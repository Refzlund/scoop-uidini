# scoop-uidini

The [Scoop](https://scoop.sh) bucket for `uidini`, the command-line client for [uidini](https://uidini.com).

```powershell
scoop bucket add uidini https://github.com/Refzlund/scoop-uidini
scoop install uidini
```

The manifest under `bucket/` is generated by uidini's release pipeline from the signed release
index at `https://dl.uidini.com/release-index.json`; each release commits a new one here.
